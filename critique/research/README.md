# Research files and reading order

This directory records the completed, bounded review for the Video 1 critique. Luna gathered candidate sources, Sol checked source claims against available texts, and Astra selected the final set on 29 September 2026. The authoritative reading order is the [eight-source shortlist](reviewed_shortlist.md), then the [evidence table](evidence_table.md), followed by the [review audit](review/review_audit.md) for candidate coverage, checks, and access limits.

The selected set contains eight published references: six empirical papers and two scholarly reviews or commentaries. The audit records 15 reviewed candidates. The [reviewed candidates file](review/reviewed_candidates.md) preserves the broader candidate set, including reserves and exclusions.

The remaining files provide context rather than changing the selected evidence: [lecture topic selection](background/lecture_topic_selection.md) and [research protocol](background/research_protocol.md). The [archive](archive) contains earlier selection notes and partial work. In particular, files in [archive/gathering](archive/gathering) are raw **UNREVIEWED** source-gathering notes; they are not source-checked conclusions and do not supersede the selected shortlist or evidence table. Archived partial review notes are historical work products, not the current authoritative review.

The selected evidence establishes some later nonreport and some delayed recollections, as well as deliberate retrieval control in laboratory tasks. It does not estimate how often protective blocking causes a memory gap in someone unsure whether an event occurred. That boundary, along with source-specific caveats, is documented in the [evidence table](evidence_table.md) and [review audit](review/review_audit.md). Research selection is complete for this pass. The [thesis synthesis](thesis_synthesis.md) compares three formulations and recommends a thesis mapped to a [920-word outline](../plan/04-argument-outline.md). This is proposed for user review, not user-approved. Essay drafting and final APA reference checking remain outstanding.
