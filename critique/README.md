# PSYC1003 critique essay

This project develops a 750–1,000-word critique of Video 1, which claims that uncertainty about a possible traumatic event usually reflects protective memory blocking. The essay weighs scientific evidence for and against that explanation and considers how the message might help or mislead viewers without scientific training.

The [checklist](#checklist) tracks the work through the numbered stages below. Begin with the assignment requirements in `00`, develop the argument in `01`, and use the evidence in `02` to write and revise the essay in `03`. The finished essay and submission receipt belong in `04`.
