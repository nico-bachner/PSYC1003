# PSYC1003 critique essay

This project develops a 750–1,000-word critique of [Video 1](00-requirements-and-materials/transcript.txt), which claims that uncertainty about a possible traumatic event usually reflects protective memory blocking. The essay weighs scientific evidence for and against that explanation and considers how the message might help or mislead viewers without scientific training.

## Project structure

```text
critique/
├── README.md            # This file
├── CHANGELOG.md         # Records project changes – especially useful for agents
├── materials/
│   ├── instructions.md  # Teacher-provided instructions, with an appendix adding omitted information
│   ├── rubric.pdf       # Teacher-provided marking rubric
│   └── transcript.txt   # Video 1 transcript 
└── sources/             # Downloaded PDF copies of the sources
```

The [materials](materials/) and [sources](sources/) are not to be modified. Additional lecture materials and course readings are available in [the course folder](../course/).
