# PSYC1003 critique essay

## Project structure

```text
critique/
├── README.md              # This file
├── CHANGELOG.md           # Records project changes – especially useful for agents
├── essay/
│   ├── arguments.md       # WIP arguments list
│   ├── draft.md           # WIP draft
│   └── evidence.md        # WIP evidence table
├── materials/
│   ├── instructions.md    # Teacher-provided instructions, with an appendix adding omitted information
│   ├── rubric.pdf         # Teacher-provided marking rubric
│   └── transcript.txt     # Video 1 transcript generated from the teacher-provided video
└── sources/               # Downloaded PDF copies of possible sources
```

The [materials](materials/) and [sources](sources/) are not to be modified. Additional lecture materials and course readings are available in [the course folder](../course/).
