# 5. Set up the document and references

[Plan index](README.md)

- [ ] Use 12-point Arial or Times New Roman and double spacing.
- [ ] Create an original title and indicate the selected video number near it.
- [ ] Include a cover page with the title, student ID, and course title. Tutor’s name is optional.
- [ ] Include introduction, body, conclusion, and reference list. Body section headings are optional.
- [ ] Do not include an abstract or appendices.
- [ ] Use APA 7 for in-text citations and the reference list.
- [ ] Check that every in-text citation has a matching reference and every listed reference is cited.
- [ ] Count the essay text, including in-text citations and subheadings; exclude the cover page and reference list.

**Details needed before finalisation:** student ID and exact course title; tutor’s name only if desired. These do not block research.

The permitted range is **750–1,000 words**. The instructions specify a 2.5% penalty at 1,001–1,100 words, plus a further 2.5% for every additional 50 words thereafter.

## Agreed drafting and finalisation workflow

1. **Draft in Markdown.** Use `critique/draft/essay_draft.md` as the authoritative prose draft, with readable author–date citations and a separate references section. Keep research notes in `critique/research/evidence_table.md`, organised as described in [the evidence module](03-evidence-table.md).
2. **Revise the argument before formatting.** Check claims against the evidence entries and verify reference metadata and citation–reference matching. Preserve meaningful italics. Target 920 words, counting the essay body, displayed citations and any subheadings; exclude the cover, references and Markdown syntax.
3. **Choose the final format later.** Canvas accepts **PDF, DOC, and DOCX** (confirmed by the supplied screenshot). Choose DOCX for word-processor editing or LaTeX for source editing and PDF production. A local Tectonic setup remains an option, subject to font, bibliography and export checks. No installation is needed during Markdown drafting.
4. **Migrate once the argument is stable.** Transfer the draft into the chosen format with the required cover page, font, double spacing and APA 7 references. Verify that text, citations and italics survive the transfer. Preserve the Markdown draft as a dated migration snapshot.
5. **Switch the authoritative file.** After migration, make revisions in the DOCX or `.tex` source. Do not regenerate from an older Markdown draft and overwrite later changes.
6. **Verify the final artifact.** Recheck the word count using the final displayed essay text, including expanded citations. Render and inspect every page, checking fonts, spacing, pagination and references. Repeat after layout-sensitive edits; inspect the exact file chosen for submission in `critique/submission/`.

The final production method and choice among the permitted submission formats remain open; Markdown drafting and the separate structured evidence file are agreed.
